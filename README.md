# homebrew-kendex

Homebrew tap for [kendex](https://github.com/vanillagreencom/kendex).

```sh
# The desktop app and the kendex command together (macOS):
brew install vanillagreencom/kendex/kendex

# The CLI on its own:
brew install vanillagreencom/kendex/kendex-cli
```

The plain `kendex` name is the cask so the default install is the app;
`Casks/kendex.rb` and `Formula/kendex-cli.rb` are generated from
`packaging/homebrew/` in the main repo and bumped on each release.
